# R4.1 MAIN — Full Workflow Folder

This package contains the complete set of active workflow files needed for the current
Market Rotation + Clean-Sheet Research setup:

- `manual_rotation.yml` — production daily dashboard + GitHub Pages
- `backfill_10y.yml` — 10-year clean-sheet research workflow
- `r4_prospective_shadow.yml` — R4 forward tracker + R4 dashboard publisher
- `r4_annual_model_refresh.yml` — annual frozen R4 model refresh

This package is intentionally complete so the `.github/workflows` folder can be replaced
without deleting the production or research actions.

Install on **main** only.
